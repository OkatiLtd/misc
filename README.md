# misc

A grab-bag repository. Each subfolder is its own small static site, published via
GitHub Pages.

- **[centenary-history-home-park-golf-club/](centenary-history-home-park-golf-club/)**
  — a page-through digital edition of *The Centenary History of the Home Park
  Golf Club* (J. G. C. Pope, 1895–1995).
  Live: `https://<your-username>.github.io/misc/centenary-history-home-park-golf-club/`

Pages is served from the repo root (`main` / `/`); the empty `.nojekyll` keeps
GitHub from running Jekyll over the files.
